# Panasaurus Wings

Wings is Panasaurus's high-performance server control daemon, built in Rust for the rapidly changing gaming industry and designed to compete directly with Pterodactyl Wings. It provides enterprise-grade performance, resource hibernation, secure sandboxed file operations, real-time WebSockets, and strict Docker container isolation.

## Features

- **High-Performance Rust Core**: Built for low memory overhead, safety, and high-concurrency server management.
- **Docker Container Isolation**: Isolated game environments with strict resource caps, readonly root filesystems, and dropped capabilities.
- **Smart Hibernation**: Automatically freezes inactive servers to conserve host resources and wakes them on player connection.
- **Secure File System**: High-security, sandboxed file management preventing path traversals and protecting template assets.
- **Real-Time WebSockets**: Live console output and system resource metrics streamed via authenticated WebSocket tokens.
